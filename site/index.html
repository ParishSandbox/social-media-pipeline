This is where the social media team writes and schedules posts for Facebook and Instagram.

Open the post editor

How it works

  1. Feast-day and Sunday drafts appear automatically about three months ahead.
  2. Write or polish the caption, add images, links, or files.
  3. Set the status to Approved. The post is scheduled in Buffer automatically.
  4. Edits to a scheduled post are sent to Buffer too. Set it to Canceled to pull it.
